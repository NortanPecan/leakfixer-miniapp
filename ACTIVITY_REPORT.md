## 2. КАК СЕЙЧАС РАБОТАЕТ КАЖДАЯ АКТИВНОСТЬ

### 2.1 Силовая тренировка (GYM)

**Откуда берёт данные:**
- При нажатии на кнопку «Силовая тренировка» предлагается выбор:
  1. Открыть GYM-модуль (план тренировок) — переход на экран GYM
  2. Быстрая запись — простая форма с временем и интенсивностью
- Данные из GYM-модуля читаются из `localStorage` (ключ `leakfixer_gym_data`)
- Функция `getGymWorkoutsForDate(dateKey)` проверяет завершённые тренировки за день

**Как считает калории:**
```javascript
// Если есть данные из GYM (упражнения, подходы, веса)
calculateStrengthCalories(workoutData) {
  // MET базовый (5.0) × вес × время
  // + объём работы (вес × повторения × коэффициент)
  // Комбинация: 70% MET + 30% объём
}

// Если только время и интенсивность
calculateSimpleStrengthCalories(duration, intensity) {
  // MET: light=3.0, moderate=5.0, vigorous=6.0, circuit=8.0
  // Формула: MET × вес(кг) × время(час)
}
```

**Связь с GYM:**
- При нажатии на кнопку силовой тренировки открывается модальное окно выбора
- Если выбран GYM-модуль — вызывается `showGymScreen()`
- Если выбрана быстрая запись — открывается форма с расчётом калорий в реальном времени

### 2.2 Аэробная тренировка (зал / улица)

**Параметры:**
- Тип активности (ходьба, бег, велосипед, эллипс, гребной тренажёр, степпер и др.)
- Время (минуты)
- Дистанция (км, опционально) — скорость считается автоматически

**Формулы:**
```javascript
calculateCardioCalories({ type, durationMinutes, distanceKm, isOutdoor }) {
  // MET-значения для разных типов кардио
  // Например: бег 10 км/ч = MET 10.0
  // Формула: MET × вес(кг) × время(час)
  // Если указана дистанция — корректируем MET по фактической скорости
}
```

**MET-значения (зал):**
- Ходьба на дорожке: 4.0
- Бег на дорожке (медленный): 7.0
- Бег на дорожке (быстрый): 11.0
- Эллипс: 5.0-9.0
- Велотренажёр: 4.0-10.5
- Гребной тренажёр: 3.5-8.5
- Степпер: 8.0

**MET-значения (улица):**
- Прогулочная ходьба: 3.0
- Быстрая ходьба: 4.5
- Бег (8-9 км/ч): 8.0
- Бег (10-11 км/ч): 10.0
- Бег (12-13 км/ч): 11.5
- Бег спринт: 14.0
- Велосипед: 4.0-12.0
- Плавание: 6.0-10.0
- Лыжи: 9.0-12.0

### 2.3 Домашние упражнения

**Подтипы (15 вариантов):**

| Категория | Упражнения |
|-----------|-----------|
| Силовые | Отжимания (умеренные/интенсивные), приседания (с весом тела/с доп. весом), выпады |
| Пресс | Скручивания, подъёмы ног, планка |
| Кардио | Бёрпи, джампинг джек, альпинист, бег с высокими коленями, бокс с тенью |
| Гибкость | Йога (лёгкая/средняя), пилатес, растяжка |

**Поля ввода:**
- Для временных упражнений: время (минуты)
- Для повторительных: количество повторений
- Для смешанных: оба параметра (выбор через чекбокс)

**Формулы:**
```javascript
calculateHomeExerciseCalories({ exerciseType, durationMinutes, repetitions }) {
  // Если есть время: MET × вес × время
  // Если есть повторения: повторения × ккал_на_повтор × (вес/70)
  // Ккал на повтор (для 70 кг): отжимание=0.5, приседание=0.4, бёрпи=1.5
}
```

### 2.4 Шаги

**Параметры:**
- Количество шагов
- Интенсивность (медленная/обычная/быстрая ходьба)

**Формула:**
```javascript
calculateStepsCalories(steps, intensity) {
  // Ккал на шаг: slow=0.035, normal=0.04, brisk=0.05
  // Корректировка на вес: (вес/70)
  // Итого: шаги × ккал_на_шаг × (вес/70)
}
```

## 4. ОСТАВШИЕСЯ ОГРАНИЧЕНИЯ И СПОРНЫЕ МОМЕНТЫ

### 4.1 Приблизительные моменты

1. **Силовая тренировка без данных GYM**
   - Используется только MET × время
   - Не учитывается объём работы (веса, подходы)
   - Рекомендация: для точности лучше использовать GYM-модуль

2. **Домашние упражнения по повторениям**
   - Ккал на повтор — очень приблизительная оценка
   - Зависит от техники, амплитуды, скорости
   - Рекомендация: для точности лучше использовать время

3. **Шаги**
   - Ккал на шаг — усреднённое значение
   - Не учитывается рельеф, скорость внутри категории
   - Рекомендация: использовать с шагомером/трекером

### 4.2 Что можно улучшить в следующих итерациях

1. **Интеграция с GYM-модулем**
   - Сейчас: чтение из localStorage
   - Можно: прямой импорт данных о тренировках
   - Можно: автоматическое создание активности при завершении тренировки в GYM

2. **История активности**
   - Сейчас: только за текущий день
   - Можно: недельные/месячные сводки
   - Можно: графики прогресса по типам активности

3. **Персонализация целей**
   - Сейчас: константы в коде
   - Можно: настройка целей в профиле пользователя
   - Можно: адаптивные цели на основе истории

4. **Улучшение точности**
   - Добавить учёт пола/возраста в формулы
   - Добавить индивидуальные коэффициенты
   - Интеграция с фитнес-трекерами (Google Fit, Apple Health)

5. **База упражнений**
   - Расширить список домашних упражнений
   - Добавить фото/видео инструкции
   - Добавить сложные комбинации (суперсеты, круговые)

6. **Социальные функции**
   - Сравнение активности с друзьями
   - Челленджи и достижения
   - Уведомления о достижении целей

## 6. КАК ТЕСТИРОВАТЬ

1. **Открыть фитнес-экран**
2. **Проверить прогресс-бары** — должны показывать 0%
3. **Нажать быструю кнопку** «+ Силовая 45 мин»
   - Должна создаться активность
   - Прогресс-бар должен показать ~100%
   - Мини-итог должен обновиться
4. **Нажать на блок «Кардио в зале»**
   - Должно открыться модальное окно
   - Выбрать тип, время, дистанцию
   - Калории должны пересчитываться в реальном времени
5. **Проверить GYM-интеграцию**
   - Перейти в GYM-модуль
   - Завершить тренировку
   - Вернуться в фитнес — должен появиться значок 🔗 GYM
